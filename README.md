# 📊 Telegram Word Counter & Text Analytics Bot

A powerful Telegram utility bot designed for SEO copywriters, digital marketers, and content creators to instantly analyze text metrics directly inside Telegram.

## 🚀 Features
* **Word & Character Counts** (With and without spaces)
* **Sentence & Paragraph Tracking**
* **Estimated Reading Time** (Calculated at an average of 200 WPM)
* **Keyword Density Analysis** (Filters out common short stop-words to show the top 5 most repeated keywords)

## 🛠️ Setup & Deployment
1. Create a bot via `@BotFather` on Telegram to get an API token.
2. Deploy this repository directly to **Render** as a Web Service.
3. Add an Environment Variable on Render with the Key `TOKEN` and your Telegram token as the Value.
